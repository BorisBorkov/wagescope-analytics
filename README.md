# Заплати, цени и покупателна способност

React приложение, което показва минималната, средната и максималната заплата в България и София, инфлацията и покупателната способност. Данните са от официални източници: НСИ, Евростат, НОИ и Министерския съвет.

| Раздел | Какво показва |
|---|---|
| 1. Заплати | Минимална, средна и максимална (праг) заплата по тримесечия 2019–2026, София спрямо страната, сектори, области, средна срещу медианна заплата |
| 2. Инфлация | Годишна инфлация по месеци 2015–2026 (България и ЕС), натрупано поскъпване, групи стоки, потребителска кошница |
| 3. Покупателна способност | Реална заплата, реален ръст, минималната заплата в ЕС в евро и по покупателна сила, догонване на ЕС, линия на бедност, разходи на домакинствата |
| 4. Заключение | Изводи, изчислени от същите данни; откъде са данните и как са превърнати в JSON; методология и източници |

Всяка графика има бутон „Таблица“ със същите данни. Сумите могат да се покажат в евро или в лева, а интерфейсът е на български или английски.

## Стартиране

Нужен е Node.js 18 или по-нов.

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # готова версия в dist/
```

## Данни

```
data/raw/            суровите данни, точно както са изтеглени
  eurostat/*.json    9 набора от Евростат (JSON-stat)
  nsi/*.xlsx, *.xls  таблици на НСИ
  nsi/quarterly-releases.json   стойности от тримесечните съобщения на НСИ (PDF)
  official.json      законови и официални стойности, всяка с източник
scripts/
  fetch-eurostat.mjs   изтегля наборите от API на Евростат
  build-data.mjs       нормализира всичко и проверява източниците един срещу друг
src/data/            нормализираните JSON файлове, които приложението чете
  salaries.json  inflation.json  purchasing-power.json  sources.json
```

```bash
npm run data         # изтегля Евростат наново и пресъздава src/data/
npm run data:build   # само пресъздава src/data/ от data/raw/
```

`build-data.mjs` сверява данните между източниците. Минималната заплата се сравнява с Евростат, годишните заплати във файловете в лева и в евро, а линията на бедност на НСИ с тази на Евростат. Проверява и дали тримесечните стойности отговарят на месечните.

**Бележки за методологията**

- Всички суми са брутни месечни. До 2025 г. са в лева и са преизчислени в евро по фиксирания курс 1,95583.
- „Максимум (праг)“ е максималният месечен осигурителен доход: 2 300 € от 01.08.2026 г. За сравнение е показана и средната заплата в най-добре платения сектор (ИКТ).
- Инфлацията е по ХИПЦ на Евростат, за да е сравнима с ЕС. Данните за септември 2026 г. са експресна оценка.
- Сайтът на НСИ блокира автоматичното изтегляне. Затова файловете му са взети от архивни копия в Wayback Machine. Данните за София след III тримесечие на 2025 г. са от регионалните съобщения на НСИ. Средната заплата за страната за II тримесечие на 2026 г. е от БТА, която цитира НСИ, защото съобщението още не е в архива. Точните връзки са в `src/data/sources.json` и в раздела „Заключение“.
